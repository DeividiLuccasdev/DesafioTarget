# Desafio Target

Desafio técnico desenvolvido em C# com .NET 8.

## Exercícios

1. Cálculo de comissão por vendedor conforme as regras definidas no enunciado.
2. Movimentação de estoque com entrada e saída de produtos, identificador único e retorno da quantidade final em estoque.
3. Cálculo de juros a partir de um valor e de uma data de vencimento, considerando 2,5% ao dia.

## Como executar

```bash
dotnet run --project ./src/DesafioTarget
```
